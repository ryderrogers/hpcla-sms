SMS terms & opt-in.

Happy To Help LLC operates an automated personal-health messaging program known as biohacker-os. This page describes the messaging program, how a recipient consents to receive messages, and the disclosures required under A2P 10DLC compliance.

Program description

biohacker-os is a personal automated health-optimization system operated by Happy To Help LLC. It sends SMS notifications to the program owner's mobile phone containing biometric alerts, daily protocol reminders, scheduled supplement and training prompts, and sleep preparation cues generated by the system based on data from the owner's own wearables and calendar.

The program is operated for a single end recipient (the program owner) at a single registered mobile number. Happy To Help LLC does not solicit, accept, or send messages to any third-party phone numbers under this campaign.

How a recipient opts in

Method 1 — Direct keyword opt-in via SMS

The recipient initiates messaging by sending the keyword START to the program's registered number (310) 906-2432 from their own mobile device. This explicit act creates a documented record of consent.

Method 2 — Written authorization on file

The recipient — who is also the program owner and the registered authorized representative of Happy To Help LLC — has provided written authorization to enroll their personal mobile number in the biohacker-os messaging program. This authorization is stored at the Happy To Help LLC business address on file with the carrier and is available on request.

"By providing my phone number and sending START to (310) 906-2432, I consent to receive automated SMS messages from Happy To Help LLC's biohacker-os program containing biometric alerts and daily protocol reminders. Message frequency varies. Msg & data rates may apply. Reply HELP for help. Reply STOP to unsubscribe at any time. Consent is not a condition of any purchase."

The statement above is the exact consent language acknowledged by the recipient at enrollment.
